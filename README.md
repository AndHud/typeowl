# 🎯 Telegram Typing Bot

Бот для обучения слепой печати на русском и английском языках с поддержкой спецсимволов.

## ✨ Возможности

- 🇷🇺 **Русский язык** — полная поддержка раскладки ЙЦУКЕН
- 🇺🇸 **Английский язык** — полная поддержка раскладки QWERTY
- 🔤 **Спецсимволы** — знаки препинания, скобки, математические символы, валюты
- 📊 **5 уровней сложности** — от новичка до мастера
- 📈 **Статистика** — WPM, точность, прогресс по дням
- 🏆 **Лидерборд** — соревнуйтесь с другими пользователями
- 🔥 **Дневные серии** — мотивация заниматься каждый день
- ⌨️ **Визуальная клавиатура** — подсветка нужных клавиш
- 👆 **Пальцевые подсказки** — какой палец нажимает какую клавишу

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd typing_bot
pip install -r requirements.txt
```

### 2. Получение токена бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

### 3. Настройка токена

**Вариант А: Переменная окружения (рекомендуется)**
```bash
# Windows PowerShell
$env:TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ЗДЕСЬ"

# Linux/Mac
export TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ЗДЕСЬ"
```

**Вариант Б: Прямо в config.py**
Откройте `config.py` и замените:
```python
BOT_TOKEN = os.getenv("TELEGRAM_BOT_TOKEN", "ВАШ_ТОКЕН_ЗДЕСЬ")
```

### 4. Запуск

```bash
python bot.py
```

## 📖 Как пользоваться

### Основные команды
- `/start` — запуск бота и выбор языков
- `/menu` — главное меню
- `/stats` — подробная статистика

### Интерфейс бота

1. **Выбор языков** — при первом запуске выберите один или несколько языков
2. **Главное меню** — показывает ваш прогресс, уровень, серию дней
3. **Начать урок** — выбор уровня сложности и старт тренировки
4. **Статистика** — детальная аналитика по языкам и последним урокам
5. **Лидерборд** — топ-10 пользователей по скорости
6. **Настройки** — изменение языков обучения
7. **Справочник** — правила слепой печати и раскладки клавиатуры

### Прохождение уроков

1. Выберите уровень (доступны только пройденные + следующий)
2. Бот показывает текст для набора и визуальную клавиатуру
3. Печатайте текст в чат — бот отслеживает прогресс в реальном времени
4. В конце урока получаете: WPM, точность, время, ранг
5. Набирайте очки для разблокировки следующих уровней

## 📊 Система уровней

| Уровень | Название | Знаков | Слов | Спецсимволы |
|---------|----------|--------|------|-------------|
| 1 | Новичок | 30 | 5 | ❌ |
| 2 | Начинающий | 50 | 10 | ❌ |
| 3 | Любитель | 80 | 15 | ✅ |
| 4 | Профи | 120 | 20 | ✅ |
| 5 | Мастер | 200 | 30 | ✅ |

## 🏆 Ранги по скорости (WPM)

- 📝 **Новичок** — < 20 WPM
- 🥉 **Начинающий** — 20–40 WPM
- 🥈 **Продвинутый** — 40–60 WPM
- 🥇 **Профессионал** — 60–80 WPM
- 🏆 **Эксперт** — > 80 WPM

## 💾 База данных

Используется SQLite (`typing_bot.db`). Таблицы:
- `users` — профили пользователей
- `lesson_results` — результаты уроков
- `daily_stats` — ежедневная статистика

## 🔧 Настройка (config.py)

Основные параметры в `config.py`:

```python
LESSON_SETTINGS = {
    "min_lesson_length": 50,
    "max_lesson_length": 500,
    "chars_per_level": 100,  # знаков для следующего уровня
    "wpm_threshold": {
        "beginner": 20,
        "intermediate": 40,
        "advanced": 60,
        "expert": 80
    }
}
```

## 🌟 Советы по обучению

1. **Регулярность важнее длительности** — 15 минут каждый день лучше 2 часов раз в неделю
2. **Точность превыше скорости** — сначала учитесь печатать без ошибок
3. **Не смотрите на клавиатуру** — используйте визуальную клавиатуру в боте
4. **Правильная посадка** — сидите прямо, локти согнуты под 90°
5. **Все 10 пальцев** — каждый палец отвечает за свои клавиши

## 🐛 Решение проблем

### Бот не отвечает
- Проверьте, что токен указан правильно
- Убедитесь, что бот не заблокирован
- Проверьте логи в консоли

### Ошибка "Conflict: terminated by other getUpdates"
- Остановите другие экземпляры бота
- Подождите минуту и перезапустите

### База данных блокируется
- Убедитесь, что запущен только один экземпляр бота
- Файл `typing_bot.db` не должен быть открыт в других программах
